# Shopping List Calculator 2.2

A small maintenance update that improves settings handling and starts the app’s gradual Kotlin modernization, while keeping the familiar interface and offline operation.

## What’s changed

- Migrated the Settings screen to Kotlin, keeping Android Views and the existing design.
- Fixed budget and currency handling so in-progress edits are preserved when changing related settings.
- Improved custom-currency previews and settings persistence, with regression tests.
- Enabled R8 code and resource shrinking to keep the Kotlin-based release small.

No accounts, ads, tracking, or network features have been added. This is the first step in an incremental refactor, not a full rewrite.

## Updating

Download `shopping-list-calculator-v2.2.apk` below and install it as an update. The app uses the same package and signing key as 2.1; do not uninstall or clear storage. Version code 18 also allows an update from the privately tested 2.2-beta.1 candidate.

If you use F-Droid, you can wait for its normal build and repository update process. Availability there is not immediate or guaranteed by the GitHub release alone.

The optimized candidate was tested on a phone, including an in-place update from production 2.1 with existing lists and settings preserved. Please report any problems in [GitHub Issues](https://github.com/buildsbyben/shopping-list-calc/issues), including your Android version and steps to reproduce, without sharing private shopping data.
